HTTP TRACKER PLUS

Settings & Preferences

Window Mode

Choose how the tracker window opens. Changes take effect on next open.

Include URL Patterns

Only track requests matching these patterns. Leave empty to track all requests. Separate multiple patterns with commas, spaces, or newlines.

Exclude URL Patterns

Skip tracking requests matching these patterns. Useful for filtering out noise. Separate multiple patterns with commas, spaces, or newlines.

Mask Sensitive Fields

Hide values of headers/parameters matching these names for privacy. Separate multiple patterns with commas, spaces, or newlines.

Settings are saved automatically as you type.
