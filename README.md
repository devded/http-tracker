## 🚀 Overview

**HTTP TRACKER PLUS** is a powerful browser extension that captures and analyzes network traffic across all tabs and windows in real-time. Designed for developers and QA engineers, it provides a centralized dashboard to inspect, filter, and modify HTTP requests/responses without the noise of standard dev tools.

## ✨ Key Features

- 🎯 **Centralized Dashboard**: Monitor every tab and incognito window in one unified view.
- 🔍 **Advanced Filtering**: Use patterns to include, exclude, or block specific URLs.
- ✍️ **Header Modification**: Add or modify request headers on the fly.
- 📦 **Data Inspection**: View sorted cookies, form data, and pretty-printed JSON responses.
- 🛡️ **Security First**: Automatically mask sensitive data in screenshots.
- ⚡ **Fast & Async**: Works in the background without slowing down your browsing.
